# Verticales - Varullo

## Descripción
Esta carpeta contiene las páginas de verticales para el sitio web de Varullo.

## Verticales Disponibles

### Creadas
- agencias: Para agencias de marketing y consultorías
- ecommerce: Para tiendas online y e-commerce
- saas: Para startups y empresas SaaS

### Nuevas Verticales Creadas
- educacion: Para instituciones educativas y plataformas e-learning
- finanzas: Para fintech, bancos y servicios financieros
- healthcare: Para clínicas, hospitales y servicios médicos
- tecnologia: Para empresas de tecnología e IT
- energia: Para empresas del sector energético
- retail: Para tiendas físicas y retail tradicional
- logistica: Para empresas de logística y transporte
- manufactura: Para industria manufacturera

## Estructura
Cada vertical tiene su propio directorio con:
- page.tsx: Página principal de la vertical
- Posibles subpáginas futuras

## Uso
Para acceder a una vertical: /vertical/{nombre-vertical}
